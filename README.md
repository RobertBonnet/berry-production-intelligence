
# Berry Production Intelligence System

End-to-end analytics project simulating agricultural production monitoring.

## Features
- ETL pipeline for farm production data
- KPI dashboards for operational monitoring
- Harvest yield forecasting
- Production delay risk prediction
- Operational insights reporting

## Tech Stack
Python
Pandas
Scikit-learn
SQL
Jupyter

## Project Structure
data/ - raw datasets
notebooks/ - analytics workflows
sql/ - database schema and queries
